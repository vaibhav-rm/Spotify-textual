Quick Installation

Set up RetroSpotify in minutes with a virtual Python environment.

Alternative: Don't want to manage Python virtual environments? Download pre-built standalone binaries or learn to build them yourself in the Compilation & Releases Guide.

1

Clone Repository

Clone the project files to your local workstation.

git clone https://github.com/vaibhav-rm/Spotify-textual.git
cd Spotify-textual
2

Install System Audio Engine

Ensure `ffplay` is installed so the player can pipe audio feeds.

# Debian/Ubuntu
sudo apt install ffmpeg

# macOS
brew install ffmpeg
3

Set Up Environment & Dependencies

Initialize your virtual environment and install the required modules.

python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

Spotify API Credentials & Login Setup

Learn how to authenticate RetroSpotify instantly using PKCE or custom credentials.

1. Instant Out-Of-The-Box Login (No Configuration Needed)

RetroSpotify includes a secure **pre-configured default Spotify Client ID**, so you do not need to register a developer app or manage API keys.

  1. Launch the app using python main.py or your compiled standalone executable.
  2. On the Welcome Screen, select "1. Login with Spotify".
  3. (Optional) Enter your Spotify email/username, then click "Next".
  4. RetroSpotify will automatically spin up a temporary secure authentication server and open your default browser.
  5. Click "Authorize" on the Spotify page to link the TUI, and the client will instantly log you in and start syncing your library.

2. Use Custom Spotify App Credentials (Optional)

If you prefer to run RetroSpotify through your own personal Spotify Developer application:

  1. Navigate to the Spotify Developer Dashboard and create a new application.
  2. Add http://127.0.0.1:8888/callback as the Redirect URI settings.
  3. Inside RetroSpotify, press Ctrl+G (or go to Settings screen via the gear icon) and input your custom Client ID and Client Secret, or save them in a local .env file:
SPOTIPY_CLIENT_ID=your_custom_client_id_here
SPOTIPY_CLIENT_SECRET=your_custom_client_secret_here
SPOTIPY_REDIRECT_URI=http://127.0.0.1:8888/callback

3. Automated Spotify Connect Playback

RetroSpotify features an integrated background Spotify Connect daemon (spotifyd):

  • Upon successful login, RetroSpotify automatically provisions, downloads, and launches `spotifyd` as a background device named "RetroSpotify".
  • The app automatically connects to this background device, letting you play and stream tracks directly without keeping the official Spotify desktop application open!
  • If you ever want to transfer playback to external speakers or another Spotify app, press d to open the Devices list and choose your desired target.
