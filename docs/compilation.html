Deployment Guide

Compilation & Releases

Learn how to run RetroSpotify using pre-compiled executables or compile it yourself.

Method A: Installation from Releases

The quickest way to run RetroSpotify without installing Python, setting up virtual environments, or managing libraries.

1. Download the Executable

Head over to the GitHub Releases page and download the executable file matching your platform:

Get Latest Release (v1.2.0)

Linux Binary

Standalone executable for standard 64-bit Linux distributions.

# Make it executable and run
chmod +x retrospotify
./retrospotify

Windows Binary

Portable retrospotify.exe console executable.

# Run in PowerShell or Command Prompt
.\retrospotify.exe

Essential Requirement: FFmpeg

Even when using pre-compiled executables, RetroSpotify requires FFmpeg (specifically `ffplay`) installed and present in your system's environment PATH to stream and output audio feeds.

  • Windows: Download FFmpeg, extract it, and add the bin directory to your System PATH environment variables.
  • Linux: Install it via your package manager (e.g., sudo apt install ffmpeg or sudo dnf install ffmpeg).

Method B: Compiling from Source

Build your own standalone binary using Python and PyInstaller. This packages all scripts and assets into a single file.

1

Clone Repository

Download the codebase to your local system first:

git clone https://github.com/vaibhav-rm/Spotify-textual.git
cd Spotify-textual
2

Install Python & FFmpeg

Make sure Python 3 (with venv/pip) and FFmpeg are installed and present in your system PATH:

Linux (Debian/Ubuntu)

sudo apt update
sudo apt install python3 python3-venv python3-pip ffmpeg -y

Windows

1. Download and run Python 3 Installer (tick "Add Python to PATH").
2. Install FFmpeg and add the ffmpeg/bin folder to your Environment Variables.

3

Set Up Virtual Environment

Initialize and activate a virtual environment to isolate the build environment:

Linux

python3 -m venv venv
source venv/bin/activate

Windows (PowerShell)

python -m venv venv
.\venv\Scripts\Activate.ps1
4

Install Requirements & PyInstaller

Install the required packages along with PyInstaller to pack the application:

pip install -r requirements.txt
pip install pyinstaller
5

Compile the Software

Run the compile.py script. This will construct dynamic resource configurations and produce the standalone executable:

python compile.py
6

Locate and Run

The compiled executable will be stored in the dist/ directory:

Linux

./dist/retrospotify

Windows

.\dist\retrospotify.exe
